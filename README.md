# Blog Writing Agent

A LangGraph agent that researches a topic, plans an outline, writes the sections, and generates diagrams for the finished blog post. It comes with a Streamlit app that lets you review the outline and edit the draft before the final post is saved.

## How it works

1. **Router** decides whether the topic needs web research.
2. **Research** searches the web with Tavily and extracts evidence (only when needed).
3. **Orchestrator** produces the outline: title, audience, tone, and one task per section.
4. **Workers** write each section.
5. **Reducer** merges the sections, decides where diagrams help, generates them with Gemini, and saves the final Markdown.

Text is generated with `gemini-3.1-flash-lite` and images with `gemini-2.5-flash-image`.

## Setup

Requires Python 3.11 or later.

```bash
pip install -r requirements.txt
```

Create a `.env` file next to `streamlit_app.py`:

```
GOOGLE_API_KEY=your-gemini-key
TAVILY_API_KEY=your-tavily-key
```

`GEMINI_API_KEY` is accepted in place of `GOOGLE_API_KEY`. The Tavily key is only needed for topics that require research.

## Run

```bash
streamlit run streamlit_app.py
```

Enter a topic, approve the outline, edit the draft if you want, then approve it. Both review steps also have a reject button: rejecting the outline returns you to the topic step, and rejecting the draft discards it and returns you to the outline. Nothing is saved on a reject. The final post is saved as `<blog title>.md` in the directory you launched the app from, with its diagrams in `images/`.

You can also run the agent directly from `blog_research_writing_agent_with_image.ipynb`. The Streamlit app loads its pipeline from that notebook, so keep the two files together.
